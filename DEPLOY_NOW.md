# Smart Kids Store - Production Website

## 🚀 Deploy to Netlify (Free & Live in 2 minutes)

1. Go to: https://netlify.com
2. Drag and drop the `simple-store.html` file
3. Get instant live URL

## Files to Upload:
- simple-store.html (Main Store)
- admin-panel.html (Admin Panel)

## Your Live URLs will be:
- Store: https://yourname.netlify.app
- Admin: https://yourname.netlify.app/admin-panel.html

## Domain Setup:
- Free: Use Netlify subdomain
- Custom: Buy domain and connect

---

## Alternative: GitHub Pages

1. Create GitHub account
2. Upload files to repository 
3. Enable GitHub Pages
4. Live at: https://username.github.io/repo-name

---

## Instant Deploy Commands:

```bash
# Upload to Netlify via CLI
npm install -g netlify-cli
netlify deploy --prod --dir .
```
