# قائمة الإدارة المشتركة

القائمة في `public/js/admin-navigation.js` هي مصدر الروابط وترتيبها والصور
المحلية ومقادير تعويض الهوامش الشفافة. التنسيق المشترك في
`public/css/admin-navigation.css`. لا تنسخ القائمة داخل صفحات الإدارة.

تستخدم الصفحات العشر `data-admin-page` لتحديد الصفحة المفتوحة، ومكانًا واحدًا
يحمل `data-admin-navigation` لتركيب القائمة. يُنقل زر الخروج نفسه إلى شريط
الموبايل عند إغلاق القائمة، ثم يُعاد إليها عند فتحها؛ لا تتكرر استمارة الخروج.
لا تخزن القائمة جلسات أو صلاحيات ولا تستبدل التحقق على الخادم.

حجم العمود على الكمبيوتر 336px، مع صور Home الأصلية وترتيبها وصورة Redirects
الجديدة ومسافة مرئية 12px. تتضمن القائمة Home وOrders وProducts وInventory
وCollections وCustomers وTheme وDiscounts وRedirects وAbandoned Checkouts.
على الموبايل تستخدم قائمة قابلة للفتح والإغلاق داخل تدفق الصفحة دون طبقة فوق
المحتوى. قائمة إعدادات Theme مستقلة داخل محتواه.

تم اختبار الروابط العشرة والعودة إلى Home لكل منها على عرضي 1365px و390px،
والصفحة النشطة وزر خروج واحد وفتح/إغلاق قائمة الموبايل وعدم تغطية المحتوى،
وتناسب الصور ومسافة 12px وتبويبات Theme الداخلية. حُمّلت بيانات الصفحات دون
أخطاء HTTP أو استثناءات JavaScript، ودون تجاوز عرض الشاشة. الفحص على Chrome
محلي معزول وNode 24؛ لم تُختبر تعديلات البيانات أو أجهزة موبايل فعلية.
