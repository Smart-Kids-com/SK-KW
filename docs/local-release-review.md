# حزمة الإصلاحات المحلية للمراجعة — 11 أكتوبر 2026

الحزمة للمراجعة فقط؛ لم تُنشأ commit أو تُرفع تغييرات أو يُنشر موقع. البيع يبقى موقوفًا، وربط Git بالنشر التلقائي يبقى مفصولًا. لا تغيير لكلمة المرور أو OTP أو تسوية المخزون.

## ما تتضمنه الحزمة

- إصلاحات المصادقة والجلسات وحماية المسارات وOrigin، والتسعير الخادمي ودورة المخزون والمعاملات والتحقق من المخطط والمسارات.
- إصلاحات القوائم والكتالوج والسلات والعناوين والتنقل الإداري، مع الحفاظ على التصميم الحالي وأصوله.
- الفاتورة من بيانات الطلب المحفوظة، بصمة لكل نسخة ومنع تكرارها، مراجعة سجلات الإرسال القديمة، وإظهار الحالة في الإدارة.
- تعطيل أزرار التحصيل الإلكتروني وOn hold غير المدعومة؛ لا تنفيذ جديد لهاتين الوظيفتين.
- أدوات التجربة المعزولة والاختبارات المرتبطة، قوالب إعداد بلا قيم سرية، وقواعد استبعاد ملفات البيئة والقواعد وملفاتها الجانبية والاعتمادات المشفرة.

قائمة الملفات الدقيقة وبصماتها محفوظة محليًا في `release-package-review.local.json`. هذه قائمة سماح، وليست إذنًا بتنفيذ `git add .`. استُبعدت سجلات التفعيل والنسخ الاحتياطية وخطط التنفيذ القديمة وملف موافقة تسوية المخزون وأدوات التنفيذ التشغيلية المرتبطة بها، مع إبقائها محليًا دون حذف. بعض ملفات التوثيق المضمّنة تحفظ حالات تاريخية؛ الحالة الحالية في أعلى `backend-audit-status.md` وهذا الملف هي المرجع للنطاق الحالي.

## التطبيق المطلوب لاحقًا بعد الموافقة

الترحيل الجديد الوحيد المحدد هو `migrateOrderInvoices` في `db/order-invoice-migration.js`: إنشاء `order_invoice_versions` بمفتاح مركب `(order_id, version)` وعلاقة بالطلبات. لا تغيير في بيانات الطلبات أو المخزون أو المصادقة، ولا تحويل تلقائي للسجلات القديمة. السجلات القديمة بلا بصمة تتطلب مراجعة صريحة في الإدارة قبل السماح بإرسال نسخة محدّثة أو تسجيل أن الحالية أُرسلت.

المقارنة مبنية على أدلة تفعيل الإنتاج المحفوظة في 10 أكتوبر وعلى سجل إضافة ترحيل الفاتورة محليًا لاحقًا؛ لم يُجر استعلام جديد للإنتاج في هذه الجولة. لذلك يلزم عند التطبيق المصرح به تأكيد وجود الجدول أو غيابه ومطابقة مخططه، ثم استدعاء ترحيل الفاتورة وحده قبل تشغيل كود الفاتورة الجديد. لا تشغّل الترحيل العام `migrateStore` أو `migrateActivation` ولا أدوات تسوية المخزون. لا تُعاد ترحيلات المصادقة والتسعير والمخزون التي اكتملت وفق الأدلة السابقة.

## حدود التحقق

فُحصت ملفات قائمة السماح بحثًا عن قواعد SQLite بمحتواها وأسماء قواعد/ملفات بيئة، وتواقيع مفاتيح خاصة وJWT وتوكنات GitHub وResend وAWS، مع مراجعة مواضع إعدادات الاعتماد والقالب. لم تظهر أسرار تشغيلية بهذه المراجعة؛ بيانات اعتماد الاختبارات اصطناعية أو مولدة ومعزولة. الفحص ليس إثباتًا شاملًا لغياب كل نوع ممكن من الأسرار، ولا يعالج مراجع PRs لدى GitHub؛ طلب الدعم مؤجل.

لم تُعد اختبارات ناجحة أو تسوية أو فحوص تنظيف التاريخ. أدلة التحقق السابقة تشمل إرسال الفاتورة وتعديل الطلب وحفظ الكميات والإجمالي والعنوان وإرسال النسخة المحدّثة ومنع تكرارها عبر Chrome وقواعد مؤقتة وبريد وهمي، واختبار رفض العمليات غير المدعومة دون تغيير الطلب أو المخزون. لم يُختبر تسليم بريد حقيقي أو موبايل فعلي للفواتير أو اختبارات تشغيلية إضافية. الباك إند ككل لا يُعلن مكتملًا.

التحصيل الإلكتروني وOn hold وطلب الدعم والاختبارات التشغيلية الإضافية مؤجلة. تصفير النافد مؤجل بقرار المستخدم؛ فتح البيع يحتاج تعليمات مستقلة لاحقة.
