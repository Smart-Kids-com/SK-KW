Discounts

One discount per order. Entering a code replaces automatic discounts. Without a code, the largest eligible automatic saving wins (oldest ID breaks ties). Free shipping is a discount against the original shipping charge. Usage is consumed once when an order is created, including pending orders; cancellation does not reset it.

Create discount

Available to everyone. Per-customer limits and selected customers are unavailable: checkout does not authenticate customer identity. Usage counts are server-managed. Product / collection scope applies to eligible units; minimum purchase uses the full subtotal. A free-shipping discount requires an eligible unit but waives the order shipping charge.
